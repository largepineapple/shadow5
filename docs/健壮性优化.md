# 健壮性优化记录

本轮针对后端状态一致性、参数接口校验、前端状态动效和异常交互进行修复。

- TaskLifecycle：通过独立 Spring Bean 的 @Transactional 方法保证阶段切换/步骤插入、成功收尾、失败收尾各自原子；数据库任务行锁与更新影响行数防止重复完成和终态回退。
- Pipeline：保留原始异常，错误日志关联任务；失败收尾写库失败后暂停领取，调度重试失败记录，不重跑制作。结果提交失败尝试清理本次图片，路径只接受 UUID。
- API：Bean Validation 校验请求体和查询/路径参数；拒绝未知 JSON 字段及小数整数；分页越界明确 400。统一 code/message/fieldErrors/requestId，401/403 过滤器也遵守，405/415 保留正确状态与响应头。
- 查询：任务详情在只读 REPEATABLE_READ 事务内获取状态与步骤，避免跨阶段快照混用。
- DTO：任务/素材响应与数据库模型分离，不暴露 userId 和模拟内部快照。
- 前端：上传组件使用模板 MIME/大小；取消选图保留素材；替换/移除取消旧请求，迟到响应无效；结果图片加载异常不影响任务成功，独立重试。
- CSS 动效：只跟随真实状态，上传遮罩/状态脉冲/结果淡入/按钮反馈，支持减少动态效果，不引入动画依赖。

验证结果：前端 lint、类型检查、10 项测试及生产构建通过；最新 Java 本地验证共 21 项，16 项通过，5 项真实 MySQL 测试在本地明确跳过。远端基线 dabce2d983bc35effe65ca71890b8ea683ec0455 的全部 CI 作业通过（https://github.com/largepineapple/shadow5/actions/runs/40875711195），包括当时全部 20 项 Java/MySQL 测试、Compose 容器启动和真实 Chromium 交互。最后新增 UUID 大小写回归测试，使 Java 总数增至 21 项，随最终提交再次运行完整 CI。

Chromium 已验证真实上传、成功结果、指定阶段失败、刷新恢复、查询异常恢复、独立会话隔离、375px 小屏无横向溢出和减少动态效果。已查看桌面模板列表及小屏历史截图，布局正常。截图可在上述 CI 的 browser-screenshots artifact 获取；未宣称完成所有浏览器和完整人工交互验收。CI 固定 Ubuntu 24.04，避免 runner 升级导致浏览器工具依赖不兼容。
